# 충전 로그 (ChargeLog)

갤럭시 등 Android 단말의 충전·방전 이력을 기록하고 시각화하는 앱입니다.
루트 권한이나 시스템 로그 없이 공식 배터리 브로드캐스트(`ACTION_BATTERY_CHANGED`)만 사용하며,
인터넷 권한이 없어 데이터는 기기 안에만 저장됩니다.

## 기능

- 충전 시작 시각·SOC, 충전 종료(분리) 시각·SOC, 최고 SOC 도달 시각 기록
- 충전–방전 세션별 사용량, 지속 시간, 시간당 변화율, 충전기 종류, 최고 온도
- 일일 사용량(하루 SOC 감소 합계, 100% 초과 가능), 충전량, 최저·최고 SOC
- 주간 막대 차트(지난주 평균 비교)와 날짜별 24시간 SOC 곡선
- 통계 탭(7/30/90일): 평소 하루 사용량·평균 최저/최고 SOC·하루 충전 횟수, 오늘 vs 평소,
  일일 사용량·SOC 범위 차트, 충전 습관, 일별 표
- 세션 탭: 날짜별로 누적되는 충전·방전 세션과 일별 요약
- 기록 유지: 배터리 최적화 제외 안내, 15분 간격 점검 알람으로 중단 시 자동 재시작
- CSV(SOC 기록 / 세션 / 일별 요약)와 JSON(전체) 내보내기

## 설치

앱 코드를 푸시하면 GitHub Actions가 APK를 빌드해 Releases에 올립니다.
폰에서 Releases의 `ChargeLog-*.apk`를 내려받아 설치하세요.
첫 실행 후 **데이터 탭 → 배터리 최적화에서 제외**를 설정해야 기록이 끊기지 않습니다.

## 직접 빌드

```
./gradlew testDebugUnitTest assembleRelease
```

Android Studio 또는 Android SDK(API 35)와 JDK 17이 필요합니다.

## 구조

| 경로 | 내용 |
|---|---|
| `core/` | 순수 Kotlin: 세션 판정(`Tracker`), 일별 집계(`Stats`), CSV 포맷 |
| `data/` | SQLite 저장소, 브로드캐스트 파싱, 내보내기 |
| `service/` | 상시 기록용 포그라운드 서비스, 부팅 후 재시작 |
| `ui/` | 홈·세션·데이터 화면과 차트 뷰 |

## 서명 키

`signing/chargelog.jks`는 빌드마다 같은 서명으로 덮어 설치할 수 있도록 저장소에 포함한
개인용 키입니다. 스토어 배포에는 사용하지 마세요.
