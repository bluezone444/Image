# 동천동 유치원 찾기

수지구 동천동 반경 5km · 2023년 4월생 기준으로 수지구·분당구·기흥구 유치원의 연령별 정원/현원을 보여 주고 추천 순위를 매기는 화면입니다.

- 반은 출생연도로 표시: 2023년생은 2026학년도 어린이집 2023년생 반(만2세반) → **2027학년도 유치원 첫해 반(만3세반·5세반)**
- 2027 예상 여석 = 유치원 첫해 반은 모두 신입이라 그 반 정원 전체, 윗반은 정원 − 한 살 아래 반 현원
- 엄마 PICK 탭: 단지 시립 어린이집·폴리 수지캠퍼스(ECP)·성민프리미어(수지)·베스아이 4곳 정밀 비교 (등원·이른 등원·하원, 월 부모 부담, 지원금, 교사 비율, 입학 난이도, 출처 링크)
- 거리 = 동천동 행정복지센터 부근에서의 직선거리. Apps Script가 주소를 좌표로 바꿔 계산(좌표는 저장돼 다음부터 빠름). 좌표가 없으면 동 중심 기준 "약 ○km"
- 반경 2/3/5/7km·전체 선택, 📍 버튼으로 현재 위치 기준 전환
- 통학 예상시간(🚗 차량/🚶 도보, OSRM 오픈스트리트맵 경로)·통학시간 순 정렬, 카드의 🧭 길찾기로 네이버 지도 앱 경로
- 필터: 최대 통학시간, 여석, 통학차량, 방과후, CCTV, 설립유형, 표시 개수(10/20/전체)
- 탭: 맞춤 추천 / 유치원 / 영어유치원(나이스 학원정보) / 비교(최대 4곳, 원비·설명회·메모 직접 입력)
- 맞춤 추천: 통학·학비·하원·등원·입학 가능성·통학차량·공간·교사 비율·안전·건물 연식을 0~1로 점수화해 중요도(무관/보통/중요/매우)로 가중 평균, 장점·확인할 점 자동 정리. 프리셋: 균형/맞벌이/가까운 곳/학비 절약/시설·안전
- 추천 점수 = 가까울수록 + 여석 + 국공립 가산 + ★관심
- 통학차량(🚌 배지·필터), 방과후 과정·급식 정보도 함께 표시 (Apps Script 실행 시)
- 시설: 공시 데이터로 건물·교실·체육장 등을 문장으로 설명, 홈페이지·블로그에서 수영장·텃밭·숲체험 같은 시설 키워드 수집(출처 링크)
- 커뮤니티: 네이버 검색 API(블로그·카페)로 원비 언급과 좋다는/아쉽다는 이야기 수집 — NAVER_CLIENT_ID/SECRET 필요
- 사건·사고 보도: 구글 뉴스 RSS로 집 7km 이내 유치원 이름+사건 단어(학대·사고·식중독·행정처분 등)가 제목에 함께 있고 용인·성남 지역 기사만 경고 표시, 필터로 제외 가능
- 화면은 휴대폰 다크 모드와 상관없이 항상 밝은 테마
- 로드뷰: 카카오맵 로드뷰 링크, 비교 탭에서 유치원·영어유치원을 이름으로 찾아 섞어 담기
- `updateSheet` 실행 시 시트 `유치원_5km`(가까운 순)와 `유치원_전체` 생성

## 쓰는 법

1. [유치원알리미 Open API](https://e-childschoolinfo.moe.go.kr/openApi/openApiIntro.do)에서 인증키 무료 신청
2. **간단히**: `index.html`을 열고 인증키 입력 → 불러오기
   - 브라우저 보안(CORS)으로 막히면 "JSON 붙여넣기"로 지역별 API 결과를 붙여넣기
3. **휴대폰 웹앱 (추천)**: 구글시트 → 확장 프로그램 → Apps Script
   - `Code.gs` 붙여넣고 `API_KEY` 입력
   - HTML 파일 `index` 추가 후 `index.html` 붙여넣기
   - `updateSheet` 실행(첫 실행 때 권한 허용) → 시트에 정리
   - 배포 → 새 배포 → 웹 앱 → 휴대폰으로 링크 열기 → 브라우저 메뉴 "홈 화면에 추가"하면 앱처럼 사용

정원·현원은 공시 기준일 값이라 실제 모집 인원과 다를 수 있습니다. 모집 요강은 처음학교로·각 유치원에서 확인하세요.
