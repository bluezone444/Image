# 동천동 유치원 찾기

수지구 동천동 반경 5km · 2023년 4월생 기준으로 수지구·분당구·기흥구 유치원의 연령별 정원/현원을 보여 주고 추천 순위를 매기는 화면입니다.

- 2023년생 → 2026학년도 **만3세반**, 2027학년도(내년 3월) **만4세반**
- 2027 예상 여석 = 만4세 정원 − 현재 만3세 현원(그대로 진급 예정인 아이들)
- 거리 = 동천동 행정복지센터 부근에서의 직선거리. Apps Script가 주소를 좌표로 바꿔 계산(좌표는 저장돼 다음부터 빠름). 좌표가 없으면 동 중심 기준 "약 ○km"
- 반경 2/3/5/7km·전체 선택, 📍 버튼으로 현재 위치 기준 전환
- 추천 점수 = 가까울수록 + 여석 + 국공립 가산 + ★관심
- 통학차량(🚌 배지·필터), 방과후 과정·급식 정보도 함께 표시 (Apps Script 실행 시)
- `updateSheet` 실행 시 시트 `유치원_5km`(가까운 순)와 `유치원_전체` 생성

## 쓰는 법

1. [유치원알리미 Open API](https://e-childschoolinfo.moe.go.kr/openApi/openApiIntro.do)에서 인증키 무료 신청
2. **간단히**: `index.html`을 열고 인증키 입력 → 불러오기
   - 브라우저 보안(CORS)으로 막히면 "JSON 붙여넣기"로 지역별 API 결과를 붙여넣기
3. **휴대폰 웹앱 (추천)**: 구글시트 → 확장 프로그램 → Apps Script
   - `Code.gs` 붙여넣고 `API_KEY` 입력
   - HTML 파일 `index` 추가 후 `index.html` 붙여넣기
   - `updateSheet` 실행(첫 실행 때 권한 허용) → 시트에 정리
   - 배포 → 새 배포 → 웹 앱 → 휴대폰으로 링크 열기 → 브라우저 메뉴 "홈 화면에 추가"하면 앱처럼 사용

정원·현원은 공시 기준일 값이라 실제 모집 인원과 다를 수 있습니다. 모집 요강은 처음학교로·각 유치원에서 확인하세요.
